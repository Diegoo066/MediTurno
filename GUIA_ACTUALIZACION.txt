MEDITURNO - GUIA LOCAL ACTUALIZADA

1. Enciende MySQL/MariaDB y verifica las credenciales locales en backend\.env.
2. Si la base de datos ya existe, no ejecutes de nuevo database\schema.sql.
3. Desde backend ejecuta npm.cmd install y npm.cmd run db:migrate.
4. La migracion es no destructiva: conserva medicos y reservas. El marcador de migracion evita volver a crear horarios demo despues de que hayan sido eliminados intencionalmente.
5. Genera el hash administrativo con npm.cmd run admin:hash y configura ADMIN_EMAIL, ADMIN_PASSWORD_HASH y AUTH_SECRET solo en backend\.env.
6. Ejecuta npm.cmd run dev en backend.
7. En otra terminal ejecuta npm.cmd install y npm.cmd run dev dentro de frontend.
8. Comprueba http://127.0.0.1:3001/api/health y http://127.0.0.1:3001/api/doctors.
9. Abre http://127.0.0.1:5173/ y prueba disponibilidad con datos ficticios.
10. Abre http://127.0.0.1:5173/admin/ e inicia sesion con el administrador configurado localmente.

Notas:
- Los horarios usan America/Lima y bloques de 30 minutos.
- No hay servicio de correo ni notificaciones externas.
- No publiques backend\.env, contrasenas, tokens, datos de pacientes ni volcados SQL.
- Para detener los servidores usa Ctrl+C en sus terminales.
